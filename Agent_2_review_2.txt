### 1.3 Claims that are **INCORRECT or OVERSTATED** in the Review

#### ✗ Absolute Continuity Direction (Lines 340-342)
**Review's claim**: "You state P_θ ≪ Q and then claim 'P_θ(x) > 0 whenever Q(x) > 0,' which is the *opposite direction*. Finite KL(Q||P_θ) actually requires Q ≪ P_θ."

**Verdict: INCORRECT—THIS IS THE REVIEW'S ERROR.** 

Examining the manuscript text:
> "P_θ ≪ Q is known as absolute continuity. Whenever the training data assigns zero probability to a sequence, the trained model also assigns zero probability... P_θ(x) > 0 whenever Q(x) > 0"

The manuscript actually states "P_θ(x) > 0 whenever Q(x) > 0," which is indeed the definition of **Q ≪ P_θ** (Q is absolutely continuous with respect to P_θ), not P_θ ≪ Q. 

**The review is correct that there's an error**, but identifies it backwards. The manuscript writes "P_θ ≪ Q" but then describes the property of Q ≪ P_θ. The manuscript's prose ("P_θ(x) > 0 whenever Q(x) > 0") is correct for the KL divergence to be finite—the *symbol* P_θ ≪ Q is wrong. So the review correctly identifies a problem but misdiagnoses its nature.

#### ✗ "0 < p+q < 1" Constraint (Line 616)
**Review's claim**: "Says 0 < p+q < 1 but correct bound is 0 < p+q < 2."

**Verdict: MISLEADING.** While it's true that p, q ∈ (0,1) means p+q could range up to nearly 2, the manuscript's constraint p+q < 1 is not wrong—it's a *sufficient condition* for convergence, not a necessary one. The eigenvalue |1-p-q| < 1 requires |p+q - 1| < 1, i.e., 0 < p+q < 2. But assuming p+q < 1 is a reasonable modeling choice that ensures the second eigenvalue is positive. The review presents this as an error when it's actually a design choice (albeit one that could be relaxed).

#### ✗ "p+q = 1" Interpretation Error (Line 538)
**Review's claim**: "Text says 'In this binary model p+q=1' which is false."

**Verdict: MISREAD.** Looking at the manuscript:
> "In this binary model the two flip probabilities satisfy p+q=1, meaning every update attempt switches an actor's belief with probability one."

This appears in the **Interpretation paragraph** after Lemma 3.2, discussing a *special case* interpretation, not claiming p+q=1 holds in general. The review misunderstood this as a general claim rather than an illustrative special case. However, I acknowledge this passage is confusingly written and could be clearer.

### 3.2 Claims that are **INCORRECT or SIGNIFICANTLY OVERSTATED**

#### ✗ "Conservation Failure" in State Updates (Lines 688-699)
**Review's claim**: "State updates add Poisson 'fabrication' term X to F but do not subtract from T, causing T+F to grow by X... This is the central mathematical flaw."

**Verdict: OVERSTATED—MISSES MODEL TRANSITION.** 

The review correctly notes that the raw update equations:
```
ΔT(t) = -Z(t) + W(t)
ΔF(t) = X(t) + Z(t) - W(t)
```
...don't conserve T+F when X(t) > 0.

**However**, the review misses a critical point: the manuscript then moves to a *different model* (Lemma 3.3) with transition matrix:
```
T_λ = [[1-(p+λ), q], [p+λ, 1-q]]
```
This is a proper stochastic matrix with conserved proportions (rows sum to 1). The fabrication λ is absorbed into the transition probability p+λ, not added as an external injection.

The manuscript is using two different representations:
1. A count-based stochastic process (raw updates)
2. A proportion-based Markov chain (T_λ)

The transition between these is admittedly unclear, but calling it "the central mathematical flaw" overstates the issue. The Markov chain analysis itself is mathematically sound.

#### ✗ "E[X_k] = λ_k" Expectation Error (Line 910)
**Review's claim**: "You set E[X_k]=λ_k despite defining X_k ~ Poisson(λ_k T_k(t)), whose expectation is λ_k T_k(t)."

**Verdict: UNCLEAR WITHOUT FULL CONTEXT.** Looking at the proof in Lemma 3.4 (cross-network equilibrium), the manuscript writes:
```
E[X_k] = λ_k  (Poisson distribution)
```

If X_k ~ Poisson(λ_k T_k(t)), then indeed E[X_k] = λ_k T_k(t), not λ_k. This would be an error if the manuscript truly defines X_k that way and then claims E[X_k] = λ_k. However, at equilibrium, if the manuscript implicitly assumes proportions are normalized or uses a different parameterization, this might be intentional. Without the full context of line 910, I rate this as **possibly correct** but potentially a misread.

#### ✗ "Ad-hoc Constraint" (Eq. 884 / λ_k = d_jk p_k/(p_k+q_k))
**Review's claim**: "Introducing this constraint solely to make proportions sum to one is a red flag indicating the model is not correctly specified."

**Verdict: OVERSTATED.** The constraint equation (λ_k = d_jk × p_k/(p_k+q_k)) is presented as a *consistency condition* that ensures the mean dynamics are well-posed. In mean-field models, such constraints are common and don't indicate misspecification—they indicate parameter relationships required for equilibrium existence. The review frames this as a flaw when it's actually standard modeling practice.
